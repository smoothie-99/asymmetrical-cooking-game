# 🛠️ 트러블슈팅: 인게임 주요 액션 확인 다이얼로그(Confirmation Dialog) 구현 및 예외 처리 (260322)

## 1. 이슈 개요 (Problem)
- **발생 상황**: '다시하기', '라운드 선택', '메인으로'와 같은 게임의 흐름을 결정하는 중요한 버튼을 클릭했을 때, 별도의 확인 절차 없이 즉시 실행됨.
- **주요 증상**: 
  - 실수로 버튼을 클릭했을 때 게임이 즉시 종료되거나 재시작되어 사용자 경험(UX) 저해.
  - 일시정지(Pause) 상태에서 다이얼로그를 띄울 때 배경 메뉴(일시정지 창)와 겹치거나 뒤로 숨는 레이어 우선순위 문제 발생.
  - 다른 플레이어에 의해 일시정지가 해제되거나 라운드가 전환될 때, 본인 화면에 열려 있던 다이얼로그가 자동으로 닫히지 않고 다음 화면(주문창 등) 위에 잔상으로 남는 버그 확인.

## 2. 근본 원인 분석 (Root Cause)
1. **확인 절차 부재**:
   - 기존 UI 버튼들이 `OnClick` 시 즉시 네트워크 RPC나 씬 전환 함수를 호출하도록 설계되어 있어 실수를 방어할 수 없음.
2. **UI 레이어링(Sorting Order) 이슈**:
   - 유니티 UI 하이라키 구조상 확인 창이 하단에 배치되어 있어도, 배경이 되는 패널에 별도의 Canvas Sorting이 적용되어 있을 경우 확인 창이 시각적으로 뒤로 숨는 현상 발생.
3. **상태 동기화 및 초기화 누락**:
   - 다이얼로그의 활성화 상태와 실행될 동작(`Action`)이 로컬 인스턴스 변수로만 관리되어, 씬 전환이나 전역 상태(`MetaState`) 변경 시점에 명시적으로 초기화되지 않아 이전 상태가 유지됨.
4. **입력 우선순위 처리 부재**:
   - ESC 키 입력 시 현재 떠 있는 최상위 창(다이얼로그)을 먼저 닫는 로직이 없어, 다이얼로그가 떠 있는 상태에서 배경의 메뉴만 닫혀버리는 부자연스러운 조작감 제공.

## 3. 해결 설계 및 구현 (Solution Design)
1. **공통 확인 다이얼로그 시스템 구축**:
   - `InGameMenuUI` 및 `EvaluationUI`에 범용적인 `OpenConfirmDialog(message, Action)` 함수 구현. 
   - 델리게이트(`System.Action`)를 활용하여 사용자가 '확인'을 눌렀을 때만 원래 의도했던 로직이 실행되도록 콜백 방식으로 캡슐화.
2. **Canvas Override Sorting 적용**:
   - `LocalConfirmPanel`에 별도의 `Canvas` 컴포넌트를 추가하고 `Override Sorting`을 활성화. `Sort Order`를 최상위값(예: 100)으로 설정하여 배경 메뉴를 끄지 않고도 그 위에 자연스럽게 덮이는 Overlay 방식 구현.
3. **전역 상태 연동 초기화 (State-Aware Reset)**:
   - `HandleGlobalMetaStateChanged`(메인 메뉴/라운드 선택 진입 시) 및 `SyncPauseState`(일시정지 해제 시) 콜백 내에 확인 다이얼로그 강제 닫기 로직 추가.
   - 게임 상태가 변할 때 열려 있는 모든 로컬 다이얼로그를 청소하여 UI 잔상 문제 해결.
4. **ESC 키 입력 핸들링 최적화**:
   - `Update` 루프 내 ESC 입력 시 다이얼로그 활성화 여부를 최우선 체크. 다이얼로그가 열려 있다면 배경 메뉴를 조작하는 대신 다이얼로그 자체를 취소(닫기)하도록 처리하여 직관적인 조작 구현.

## 4. 최종 결과 (Result)
- **사용자 실수 방지 및 UX 품질 향상**: 
  - 중요 액션 실행 전 재확인 단계를 추가하여 의도치 않은 게임 중단 방지. 가독성을 위해 문구에 줄바꿈(`\n`)을 적용한 2줄 레이아웃 도입.
- **UI 잔상 및 꼬임 현상 해결**: 
  - 타인에 의한 일시정지 해제나 강제 라운드 이동 시에도 UI가 자동으로 정리되어 데이터와 비주얼 간의 동기화 불일치 100% 제거.
- **안정적인 오버레이 시스템**: 
  - 하이라키 구조에 의존하지 않는 독립적인 Sorting 시스템으로 어떤 메뉴 위에서도 안정적으로 노출됨을 보장.

## 5. 핵심 기술 스택
- **Unity 2022.3**
- **uGUI**: Canvas Override Sorting, Graphic Raycaster.
- **C#**: Action Delegate를 활용한 콜백 패턴, MetaState 기반 상태 동기화.
